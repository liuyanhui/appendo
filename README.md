# Appendo

一个极简的 Android 速记应用：从任意应用分享内容自动收集，或手动输入，追加保存到 Markdown 文件。

## 功能特性

- **收集** — 系统分享接收（任意应用→选 Appendo）＋应用内手动输入
- **条目操作** — 点击编辑（时间戳不变）、右滑删除、多选批量；长按复制单条
- **主题分拣** — 主列表多选「移入主题」（组合事务先写后删，失败可安全重试）；主题页彩色首字标卡片、左滑改名、空主题删除
- **主题工作区** — 点击主题进入，条目编辑/删除/批量/新增/复制/分享/归档，与主界面同权；「归档并清空」＝带备份的批量清理
- **出口干净** — 复制全部/分享导出格式化纯文本（自动剥离隐形标记，任何应用完整显示）
- **归档管理** — 归档二选一（并清空／只归档）、浏览、恢复（自动去重）、删除
- **添加到日历** — 条目一键预填系统日历事件（单向、零权限；v1.5 起提醒由日历承接）
- **深色主题** — 跟随系统／浅色／深色三选，即时生效
- **存储双模式** — 默认应用私有目录（原子写入）／自定义外部目录（SAF，软恢复）

## 条目格式

```
---

## YYYY-MM-DD HH:mm:ss.SSS

{原始内容}

---
```

> 文件内时间戳毫秒级（1.0.2 起），界面显示到秒；内容原样保留不加工。

## 使用方法

- **收集**：任意应用分享→选 Appendo；或主界面「手动输入」
- **编辑/删除**：点击条目编辑；右滑删除（多选图标进批量模式）
- **移入主题**：多选勾选→「移入」→选已有主题或新建（同名/非法名有确认）
- **主题页**：顶栏「主题」进入；左滑改名、右滑删空主题；点击进工作区
- **归档**：网格「归档」对当前内容二选一备份；菜单「归档管理」管理归档文件
- **滑动差异**：主列表仅右滑删除；归档列表左滑恢复；主题列表左滑改名

## 构建

```bash
git clone https://github.com/yiyue31/appendo.git && cd appendo
./gradlew assembleDebug        # 构建 APK
./gradlew testDebugUnitTest    # 单元测试
```

要求：Android Studio Hedgehog+、JDK 17、SDK 34。

## 已知约束与数据安全说明

- **外部编辑器直编 `Appendo.md` 不支持**（内容有零宽空格隔离防误切条目；复制/分享已自动剥离，输出干净）；主题/归档文件同存应用私有目录，不经文件管理器直取
- **SAF 模式为"软恢复"**：写中途崩溃从 .bak 回滚（最近一次未完成写入可能丢，文件不损坏）；更新后若提示「数据文件访问已失效」，重选同一文件即可
- **v1.5.0 起应用内提醒退役**：旧提醒升级后不生效（不迁移）；写入日历的事件由日历应用管理，卸载不影响
- **旧数据 `---`/`# Appendo` 行**：升级后首开自动迁移修复，无需操作
- **不建议降级安装**（1.0.2 起毫秒时间戳旧版不显示，数据不丢）；单次分享上限 10,000 字符（拒绝不截断）
- **重复时间戳**（归档恢复+编辑组合的极少数场景）：删除/编辑作用于文件中靠前那条
- **多设备/云盘同步不支持**（双机同步会互相覆盖）；多选无全选/筛选，长按为全文预览
- **「复制全部」不含已移入主题条目**（主题即分拣后视图，全景取用进各主题复制——有意取舍）

## 换机与备份

- 数据随 **Android 系统云备份/恢复**迁移（含主题与归档；效果取决于厂商支持）；应用自身不联网、无第三方 SDK
- 手动迁移：「自定义目录」把数据文件放自选位置后复制，或「复制全部」导出（主题内条目分别复制）
