# Appendo

一个极简的 Android 速记应用，通过系统分享功能自动收集内容，或手动输入文字，将所有内容追加保存到 Markdown 文件中。

## 功能特性

- **分享收集** — 从任意应用分享链接或文本，自动追加保存
- **手动输入** — 在应用内直接输入文字内容，自动弹出键盘
- **内容预览** — 实时查看已收集的所有条目（按时间倒序）
- **单条删除** — 右滑删除单条内容，按时间戳精准定位
- **条目编辑** — 点击条目弹出编辑对话框，修改内容后手动保存，时间戳保持不变
- **添加到日历** — 将条目内容预填并拉起系统日历新建事件（时间与告警在日历内设置）
- **本地提醒** — 为条目设本地提醒，到点 appendo 自发通知（⏰），点按回到该条记录；支持贪睡、徽标、开机后补发；可设每天/每周重复
- **深色主题** — 菜单「外观」（v1.4 前名「主题」）三选：跟随系统（默认）/ 浅色 / 深色；选择即时生效并记住，冷启动不闪屏
- **格式保留** — 保持原始内容格式（换行、缩进、符号等），不做任何处理
- **文件管理** — 默认自动创建文件，支持自定义外部存储目录
- **移入主题** — 多选条目移入主题文档：先写入后移除的组合事务（失败可安全重试，内容不会丢）；支持新建主题（同名确认）与提醒联动取消
- **主题独立页** — 顶栏「主题」入口：彩色首字标主题卡片、只读详情、长按复制全文、左滑恢复、空主题删除
- **归档管理** — 归档旧内容、浏览归档、恢复归档到当前文档（自动去重）
- **快捷操作** — 一键复制、分享（导出为干净纯文本：秒级时间戳 + 内容，无格式标记，任何应用完整显示）、归档（二选一：归档并清空／只归档，保留列表）
- **安全写入** — 全局同步锁防止并发冲突，UTF-8 编码无 BOM

## 条目格式

每条收集的内容使用以下格式：

```
---

## YYYY-MM-DD HH:mm:ss.SSS

{原始内容}

---
```

> 文件内时间戳为毫秒级（1.0.2 起），界面显示到秒。

## 技术栈

- **语言**：Kotlin
- **UI**：Jetpack Compose (Material 3)
- **导航**：Navigation Compose
- **架构**：双 Activity + Compose Navigation
- **存储**：双模式 — 默认文件 + SAF (Storage Access Framework)
- **最低 SDK**：API 26 (Android 8.0)
- **目标 SDK**：API 34

## 使用方法

### 首次使用

1. 启动应用，自动创建默认文件
2. 开始收集内容

### 收集内容

**方式一：分享收集**
- 从任意应用（如浏览器、微信等）分享链接或文本
- 选择 "Appendo" 即可自动收集

**方式二：手动输入**
- 在主界面点击「手动输入」按钮
- 输入文字内容后点击「追加」即可保存

### 主要操作

- **查看内容** — 主界面实时显示所有已收集的条目
- **复制内容** — 将全部内容或单条内容复制到剪贴板
- **分享内容** — 将内容分享到其他应用
- **删除条目** — 右滑单条内容删除
- **滑动操作差异（主列表 vs 归档/主题列表）** — 主列表仅支持右滑删除；归档列表与主题列表为双向滑动：右滑删除（主题仅空主题可删、非空右滑无响应）、左滑恢复（追加到当前文档，自动去重）。删除手势全局一致，左滑恢复仅归档/主题列表存在
- **编辑条目** — 点击条目弹出编辑对话框，修改内容后保存
- **设提醒** — 在条目详情中为该条设本地提醒（预设网格或自定义时间）
- **添加到日历** — 将条目内容预填到系统日历新建事件
- **移入主题** — 顶栏多选图标进入多选，勾选条目后点「移入」：选已有主题或新建（非法/同名有确认），条目先写入主题文档再从主列表移除；失败可重试且内容不丢，成功/跳过/取消提醒数均在反馈中明示
- **主题页** — 顶栏「主题」入口进入：点击主题看只读详情、长按复制全文、左滑恢复到当前文档、空主题右滑删除
- **归档（二选一）** — 点击网格「归档」按钮：「归档并清空」＝先备份为归档文件再清空当前文档（并取消全部提醒）／「只归档，保留列表」＝仅生成归档副本、主列表不变。v1.4 起替代原「长按清空」，菜单「归档」项同步移除（入口唯一化到网格按钮）
- **归档管理** — 点按菜单「归档管理」**进入归档列表**：浏览、恢复（去重追加到当前文档）、删除归档文件。与网格「归档」的区别：网格「归档」是对**当前内容**做一次备份（可选同时清空），「归档管理」是管理**已生成的归档文件**
- **自定义目录** — 切换到外部存储位置
- **提醒自检** — 检查通知权限/后台运行，发送测试提醒验证本机能否触发

## 构建项目

### 环境要求

- Android Studio Hedgehog (2023.1.1) 或更高版本
- JDK 17
- Android SDK 34

### 构建步骤

```bash
# 克隆项目
git clone https://github.com/yiyue31/appendo.git
cd appendo

# 构建 APK
./gradlew assembleDebug

# 安装到设备
./gradlew installDebug
```

## 已知约束与数据安全说明

- **外部编辑器直编 `Appendo.md` 不支持**：应用对内容做零宽空格隔离，防止用户内容中形如时间戳的行被误判为条目边界。直接用其他编辑器编辑文件可能破坏该机制；复制/分享功能已自动剥离这些标记，输出干净文本。
- **SAF（自定义外部目录）模式为"软恢复"**：SAF 无原子重命名能力，写入中途崩溃会从上次备份（.bak）回滚——**最近一次未完成的写入可能丢失，但文件不会损坏**。默认（应用私有目录）模式为真原子写入，无此限制。**应用更新后若提示「数据文件访问已失效」**，重选同一文件即可恢复（部分系统会在更新时清除授权，数据不丢失）。
- **本地提醒在国产 ROM 上需开自启动**：realme/小米等激进省电会杀后台闹钟；首次到「提醒自检」开电池白名单 + 系统设置允许自启动，否则重启后提醒可能不响。完成设置后可用「发送测试提醒」当场验证（可靠非 100%）。**错过不必担心：打开 appendo 会自动补发已过期的提醒**（需先解锁手机）。**贪睡会将其后的重复提醒整体后移**（如每天 9:00 的提醒贪睡 1 小时 → 此后每天 10:00）。
- **旧数据中的 `---` 行与 `# Appendo` 开头行**：升级到 v1.2.2 后**首次打开会自动迁移修复**（补隐形保护标记），无需操作；极少数残余（条目末尾紧贴分隔线的 `---`、历史上已被当作时间戳标题拆分的行）仍不可见。
- **不建议降级安装**：1.0.2 起新条目用毫秒级时间戳，旧版本（1.0.x）无法显示这些条目——数据仍在文件中不会丢失，重新安装新版即可恢复显示。
- **同一条目的"重复时间戳"极少出现**（归档恢复+编辑的组合场景）：此时删除/编辑会作用于文件中靠前的那条。
- **清空与切换数据文件会移除全部提醒设置**（不可恢复，操作前有确认弹窗）；恢复归档只恢复条目、不恢复提醒。
- **单次分享上限 10,000 字符**（超长会被拒绝并提示，不会截断保存）。
- **多设备/云盘同步不支持**：数据文件放云盘目录做双机同步会得到过期视图与互相覆盖。
- **主题**：升级到 v1.3 后默认**跟随系统深浅色**——深色系统下界面会由原先的恒浅色变为深色；如不习惯可在 菜单「外观」（v1.4 前名「主题」，仅更名、功能不变）固定为浅色。SAF 文件选择器、系统权限对话框、输入法等系统/三方界面按系统主题渲染，不受应用内选择控制；Android 8.x/9.x 无系统深色开关，「跟随系统」在该档设备恒为浅色。
- **移入主题与提醒**：移入会同时取消所选条目**未触发的提醒**；从主题恢复条目**不会恢复提醒**（恢复是复制条目，提醒需重新设置）。
- **「复制全部」不含已移入主题的条目**：移入后主文件只保留其余条目，全景取用须进入各主题分别长按复制（有意取舍——主题即分拣后的视图）。
- **主题文档为只读视图**：不支持在主题内编辑、删除或移出单条；官方清理路径＝左滑恢复清空该主题后，右滑删除空主题。
- **主题文档存应用私有目录**（与归档文件一致）：不经「打开文件」菜单或外部文件管理器直取（内容出口走应用内长按复制——复制/分享已自动剥离隐形标记，输出干净文本）；无云备份条件下卸载即失去，有 Android 系统云备份时随备份迁移。
- **多选模式无全选/按时间筛选**（大批量分拣需逐条勾选）；多选态长按条目为全文预览，预览内可复制单条。
- **极端条件下归档/主题文件可能截断**（既有系统性边界）：默认模式的写入采用"临时文件+重命名"原子替换，仅当重命名失败退化为直接覆写、且恰在覆写中途中断的双重罕见条件下，文件原有序尾可能丢失；此后重试可保证新写入的条目完整。

## 换机与备份

- 数据文件与提醒设置会随 **Android 系统的云备份/恢复**迁移——换机时在系统设置中完成备份与恢复即可（实际效果取决于设备厂商对 Android 备份的支持程度）。
- **主题文档（`topics/` 目录）与归档文件同存应用私有目录**，随上述系统云备份迁移；无云备份条件下卸载即失去（与归档一致）。
- **应用自身不联网、不含任何第三方 SDK**；云备份由 Android 系统完成，应用不参与传输。
- 也可手动迁移：菜单「自定义目录」把数据文件放到自选位置后复制，或用「复制全部」导出全文（已移入主题的条目须在各主题页分别长按复制）。
