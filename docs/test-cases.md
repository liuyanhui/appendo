## 0. 使用说明

### 0.1 用例分层与状态

- **P0（发布门禁）**：核心路径与数据安全——发布前必须全过；
- **P1（质量门）**：重要分支与边界——每批次开发完成时过，发布前抽查（规则见 §0.3.2）；
- **P2（回归池）**：低频路径与视觉项——按需。
- **状态词表**：`现行`（默认，不标）／`本批升级`（批次内临时升级 P0，收尾时裁定回退或转正）／`退役`（标注替代 TC-ID 或退役原因）。级与状态变更一律记入修订记录。
- **ID 分段**：十位段按功能区分配（00x 主列表/01x 数据安全/02x 归档/03x 主题页/04x 工作区/05x 分享入口/06x 日历退役面/07x 视觉/08x 性能）；段满另启空段并在修订记录登记段义。

### 0.2 验证方式标注

- **JVM**：单元测试覆盖（**标注测试类**——已自动化项随套件全绿即视为过）；
- **真机**：人工走查（RMX3560；toast 观察以人眼为准——TD-024）；
- **adb 可代驱**：`input swipe` 在部分设备状态下失灵，横向滑动一律用 `motionevent` 逐点拖动（2026-11-17 在案）；
- **文件级断言配方**（时间戳毫秒/原样类断言 UI 层不可见，必须读文件核对）：
  `adb shell run-as com.yiyue31.android.appendo cat files/Appendo.md`（或 `files/topics/<名>.md`）——核对 `## yyyy-MM-dd HH:mm:ss.SSS`（毫秒形态）／无 `.SSS`（秒级旧条目原样）；
- **方式列为人工速记**：混合了通道与驱动备注两个维度；若未来接 instrumented 自动化，届时拆为「通道（JVM/Instrumented/人工）×自动化状态（已自动化/可代驱/仅人工）」封闭枚举——**在此之前不得按现格式写解析脚本**。

### 0.3 验收门槛

**0.3.1 批次门槛**（每批次开发完成时）

1. 本批 P0 用例全过＋**受影响面用例全过**——受影响面以 TC-ID 列表在批次计划的**任务拆分时**钉死；
2. **重构类批次**（组件抽取/迁出/函数提权）附加：抽取提交**独立合入、先绿后进下一任务**（沿 T-28 双门禁先例）；
3. 数据安全类与出口干净类**不适用抽查**（零容忍语义）。

**0.3.2 发布门槛**

1. 全量 JVM 单测 0 失败 0 错误（**数量以当期套件为准**，不硬编码）；
2. P0 用例全过——P0 主判据须**单一通道**（JVM 或真机），辅助性走查另标「增强」，不入门禁判据；
3. P1 中**数据安全类与出口干净类全过**；其余 P1 抽查 ≥3 项；
4. assembleDebug 成功＋TC-001 装机冷启冒烟过（证据落批次计划）；
5. CHANGELOG 对应版本段已定稿。

## 9. 已知边界与不测项（如实声明）

- 外部编辑器直编 `Appendo.md` 不受支持（README 已知限制）；
- 写入日历的事件由日历应用管理，应用不读不删（16.C 设计）；
- `input swipe` 在部分设备状态下注入失灵——自动化一律用 motionevent 逐点拖动；
- 真机 FUSE 拒绝 run-as 访问外部 Android/data——**文件级注入（chmod/直写）仅限内部 `files/topics` 候选目录**，UI 创建的主题不可注入；
- 归档文件名秒级粒度同秒覆盖（**己批次随批修复**：后缀单点统一主/题双消费——TC-098b 验收）；
- 默认模式下「打开文件」菜单用 `Uri.fromFile`（targetSdk 34）大概率抛 FileUriExposedException→toast 误导性文案（低频场景，SAF 模式正常）；
- uiMode 配置变化（系统深浅切换）触发 Activity 重建——**已修复（TD-051/N-4，2026-11-23 真机验收）**：rememberSaveable 状态提升——草稿/多选态/对话框旗标/moveFlow 过重建不丢；TC-100（三宿主腿）/101/102 真机过；TC-104 进程死亡与 TC-105 陈旧校验真机配方受限降级（am kill/kill -9/WRITE_SECURE_SETTINGS 被 ROM 拒＋外部写不触发轮询=§6.3 已知约束——JVM Saver round-trip/MoveRestoreDecision 钉死＋机制同源论证在案）；TC-106 容量降级 JVM 主判；ArchiveListScreen 恢复确认框态不保全（后置登记）。
