## 概述

一个 Android 速记应用，支持两种方式收集内容：
1. 接收由其他应用通过分享功能发送的链接或文字
2. 用户在应用内手动输入文字内容

所有内容追加保存到一个固定的 Markdown 文档中，便于整理和导出。

## 功能需求

### 接收与写入

1. **接收分享** — 作为分享目标（`ACTION_SEND`），接收 `text/plain`（文本/链接）和 `Intent.EXTRA_STREAM`（仅记录 URI 本身）
2. **手动输入** — 应用内提供对话框供用户直接输入文字内容
3. **追加写入** — 保持原有格式（换行、括号、空格、缩进等），不做任何文本处理，使用 UTF-8 编码；写入操作加同步锁防止并发冲突
4. **条目格式** — 每条记录使用以下固定模板：

```
---

## YYYY-MM-DD HH:mm:ss

{原始内容}

---
```

### 文件管理

4. **用户自选路径** — 首次启动引导用户选择 Markdown 文件保存位置，支持更换路径（更换时释放旧 URI 权限）
5. **文件头** — 首次创建时写入 `# Link Collection`；一键清理时保留文件头，仅清除条目内容
6. **文件丢失恢复** — 文件不存在或 URI 权限失效时，自动引导用户重新选择
7. **追加降级** — SAF `MODE_APPEND` 失败时，降级为先读取全部内容再整体覆写
8. **归档** — 用户可选择归档当前文件：引导创建新 Markdown 文件替换，释放旧文件 URI 权限，旧文件保留在原位置不再管理，条目计数归零

### 界面与操作

9. **主界面** — 展示当前文件目录路径、已收集条目数（通过解析 `## YYYY-MM-DD HH:mm:ss` 时间戳标题统计）
10. **内容预览** — 主界面实时显示所有已收集的条目列表，按时间倒序排列（最新的在前），每条显示时间戳和内容
11. **手动输入** — 提供「手动输入」按钮，点击弹出对话框，用户可直接输入文字内容并追加到文件
12. **打开文件** — 调用外部应用打开 Markdown 文件
13. **一键复制** — 将文件全部内容复制到剪贴板
14. **一键清理** — 弹窗确认后清空条目，保留文件头
15. **分享内容** — 将文件全部内容作为 `text/plain` 通过 `ACTION_SEND` 分享到其他应用（`Intent.createChooser`）

### 容错

14. **写入反馈** — 分享写入完成后通过 Notification 提示（避免 Activity 快速关闭导致 Toast 不显示）

## 技术要求

- 技术栈：Kotlin + Jetpack Compose
- 文件存储：SAF (Storage Access Framework)
- 最低 SDK：API 26 (Android 8.0) | 目标 SDK：API 34
